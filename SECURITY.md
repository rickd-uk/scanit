# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

https://github.com/rickd-uk/scanit/security/advisories/new

Include the affected version or commit, reproduction steps, potential impact,
and any suggested mitigation. Do not include real secrets or sensitive host
data. Please avoid opening a public issue until the report has been assessed.

## Scope

Security-relevant examples include command execution, unsafe path handling,
privilege-boundary errors, destructive remediation, evidence leaking secrets,
and checks that produce dangerous false assurances.

Ordinary false positives and feature requests can use the public issue tracker.
